# Fireflydle 支持渠道

请选择与问题匹配的渠道。公开 Issue 中的内容会被所有人看到。

| 问题类型                       | 联系渠道                                                                                     |
| ------------------------------ | -------------------------------------------------------------------------------------------- |
| 可复现缺陷                     | [缺陷报告](https://github.com/zzstar101/fireflydle/issues/new?template=bug-report.yml)       |
| 功能建议                       | [功能建议](https://github.com/zzstar101/fireflydle/issues/new?template=feature-request.yml)  |
| 角色数据纠正                   | [数据纠正](https://github.com/zzstar101/fireflydle/issues/new?template=data-correction.yml)  |
| 安全漏洞或无法脱敏的公平性问题 | [Private Security Advisory](https://github.com/zzstar101/fireflydle/security/advisories/new) |
| 账号与验证邮件                 | [account@fireflydle.games](mailto:account@fireflydle.games)                                  |
| 权利人素材下架                 | [takedown@fireflydle.games](mailto:takedown@fireflydle.games)                                |

请不要通过任何渠道发送密码、完整 Cookie、验证码或仍然有效的 token。公开报告还必须移除真实用户数据、当前或未来每日题答案、未结束对局目标，以及可以反推出答案的响应或截图。

账号与下架邮件均通过 Cloudflare Email Routing 转发给维护者。我们不会通过邮件索要密码。
