# 星神图片来源与本地化审计

T15 只发布 HoYoWiki 星神菜单中的 18 位具名星神。`packages/game-data/src/aeon-manifest.ts` 是可执行清单，逐项保存永久 ID、三语名称、人工焦点、官方页面、原始资源 URL、本地尺寸与 SHA-256。

- 14 项使用 HoYoWiki / HoYoverse 官方主图，标记为 `official-main-art`。
- 阿基维利、龙、伊德莉拉、末王没有可独立本地化且彼此唯一的官方主图，按产品例外使用各自的游戏内命途视觉，标记为 `official-path-emblem-fallback`。
- 阿基维利使用 HoYoWiki 的开拓徽记；龙使用游戏资源中的不朽徽记镜像，并以 HoYoWiki 星神条目作为官方出处。
- 伊德莉拉从 HoYoWiki 收录的官方《有关星空的寓言集·其一》纯美画面提取徽记；末王从崩坏：星穹铁道官方哔哩哔哩账号发布的同一 PV 终末画面提取徽记。成品不包含命途名称、字幕或属性文字。
- 本地路径使用无语义序号，进行中 API 因此不会通过文件名泄露答案。

Golden test 会读取实际文件并验证：18 个永久 ID 与三语名称固定、禁止 Herta 和命途名充当答案、正好 4 个徽记例外、manifest 与审计路径一一对应、文件存在且非 SVG、18 个 SHA-256 全部唯一。
