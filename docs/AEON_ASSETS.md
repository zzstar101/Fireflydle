# 星神图片来源与本地化审计

T15 只发布 BWIKI《星神》页面中有星神本体图的 14 位具名星神。`packages/game-data/src/aeon-manifest.ts` 是可执行清单，逐项保存永久 ID、三语名称、人工焦点、官方页面、原始资源 URL、本地尺寸与 SHA-256。

- 14 项使用星神本体图，统一标记为 `official-main-art`。
- 阿基维利、龙、伊德莉拉、末王在该 BWIKI 页面没有可用的星神本体图，因此不进入题池，也不使用命途徽记或其他替代图。
- 本地路径使用无语义序号，进行中 API 因此不会通过文件名泄露答案。

Golden test 会读取实际文件并验证：14 个永久 ID 与三语名称固定、禁止 Herta 和命途名充当答案、全部资产均为星神本体图、manifest 与审计路径一一对应、文件存在且非 SVG、14 个 SHA-256 全部唯一。
