# Fireflydle 设计系统

## 视觉主张

“萤一把 / Fireflydle”采用安静、精密的编辑式视觉语言，不复刻游戏原界面。主游戏棋盘是唯一视觉焦点，页面通过留白、信息带和清晰表格组织内容，不堆叠通用卡片。界面文案直接描述玩法和状态，避免用世界观名词包装普通操作。

概念图生成服务在 2026-08-01 返回 404，因此本文件作为实现前的代码化视觉规格。正式角色图由网站版本发布流程同步；设计阶段不生成或仿制官方角色。

不依赖外部字体 CDN，以保证 GitHub Pages 在不同网络环境下可用。

## 构图

- 顶部全局导航保持安静，只包含品牌、总站、排行榜、语言、主题与账号；内容模式与其实际支持的活动在模式导航带中呈现。
- 桌面游戏页使用窄左轨、宽棋盘、窄右轨；棋盘不是浮动卡片集合。
- 结果行使用票券切角与细金属边线；选中行具有低强度扫描光，不使用强霓虹。
- 移动端将两侧信息折叠为棋盘上下的信息带，五列允许横向滚动并固定角色列。
- 页面最大内容宽度为 `1440px`，主阅读宽度为 `1180px`。

## 组件族

- `AppShell`：全局导航、语言、主题、账号状态。
- `ModeShell`：由版本化内容 manifest 驱动的模式与活动导航。
- `RailPanel`：开放式信息轨，仅在功能确需分区时使用。
- `TicketButton`：小切角、金色边线、明确的 hover/focus/pressed 状态。
- `GuessBoard`：固定表头、角色列、五项反馈、版本箭头。
- `CharacterCombobox`：键盘可操作、跨语言别名、虚拟化长列表。
- `StatusCell`：正确／接近／不匹配三种语义与图纹。
- `MetricStrip`：计时、剩余次数、比分与连接状态。
- `DataTable`：排行与后台复用，桌面表格、移动端紧凑列表。
- `Dialog` 与 `Drawer`：登录、规则、结算和移动端筛选。

## 动效与无障碍

- 页面转场 160–220ms，结果翻格 420ms，计时器不做持续跳动缩放。
- 遵循 `prefers-reduced-motion`；减少动效时直接显示最终状态。
- 所有控件具有可见焦点环，触控目标至少 44px。
- 棋盘通过 `aria-live` 宣布新反馈，表格保留语义化表头。
- 深浅主题均满足正文 WCAG AA 对比度目标。
