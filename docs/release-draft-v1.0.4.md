# 萤一把 v1.0.4「玩法、图鉴与反馈更新」

> 候选稿，确认内容后再用于 GitHub Release 和站内公告。

<!-- fireflydle:announcement:start -->

## 新玩法和新收藏来啦～ ✨

这次更新重新整理了首页入口，也带来了角色立绘挑战、角色图鉴和一整套收藏奖励！

### 首页和挑战更清楚了

- 每日题、普通挑战和无尽挑战成为首页的三个核心入口。
- 无尽挑战支持连续作答、生命、最佳成绩和独立排行榜。
- 每日题改为全球同题，注册玩家可以参加每日排行榜。
- 货币战争、星神和其他玩法收进内容模式与更多玩法区域，入口不再重复堆叠。

### 猜角色立绘

- 新增 8×8 遮罩的立绘挑战，猜错后逐步揭示更多画面。
- 角色默认立绘和已整理的皮肤会等概率出现，但始终计作同一个角色。
- 复用普通角色搜索，猜中后会显示完整的成功反馈和皮肤名称。
- 新增立绘无尽：沿用五条生命、逐题结算和独立排行榜，猜错会逐步揭示更多立绘区域。

### 角色图鉴和收藏奖励

- 猜中角色后解锁角色资料、简介、命途、属性、阵营、地区、实装版本和官方立绘。
- 完成命途或阵营收集后，可以应用对应的全站主题。
- 阵营奖励使用官方场景背景，不再用单个角色立绘代替阵营奖励；细分阵营无独立素材时回退到所属地区背景。
- 图鉴地址统一为 `/collection`，旧 `/codex` 地址仍会自动跳转。

### 反馈中心

- 注册用户可以直接在站内提交 Bug、功能建议和数据纠错。
- 每条反馈最多附加 5 张截图，图片会自动压缩后上传。
- 提交后可以在“我的反馈”查看处理状态；已解决的问题会在对应版本日志中记录。

### 题库和判定调整

- 货币战争费用现在必须完全匹配。
- 补充黄泉等货币战争题库资料，并增加对应判定测试。
- 角色挑战、货币战争和无尽模式的说明与入口文案统一更新。

感谢大家的反馈，祝各位早日猜中！🎯

<!-- fireflydle:announcement:end -->

## 工程更新

- 新增角色图鉴、皮肤资料、立绘挑战、立绘无尽和站内反馈 API/前端流程。
- 增加官方阵营/地区背景素材，并在图鉴奖励卡中使用完整宽幅构图。
- 增加命途与阵营主题偏好，并限制奖励背景不影响对局判题界面。
- 增加每日题、无尽排行榜数据读取与显示。
- 修复立绘挑战加载卡住、猜中无反馈、图鉴图片裁切和阵营奖励误用角色立绘等问题。
- 已通过格式、类型检查和 Web 生产构建。
