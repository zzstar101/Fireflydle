# 萤一把 v1.1.0「挑战、图鉴、性能与稳定性更新」

> v1.1.0 正式发布日志。

<!-- fireflydle:announcement:start -->

## 新的挑战方式，更完整的收藏体验

### 首页与排行榜

- 每日题、普通挑战和无尽挑战成为首页核心入口，其他玩法收进更多玩法区域。
- 无尽挑战支持连续作答、生命、最佳成绩和独立排行榜。
- 每日题改为全球同题；当日没有成绩时，排行榜会正常显示空状态，不再被误认为接口故障。
- Elo、每日题和无尽榜分别展示，游客仍可游玩但不会进入注册用户排行榜。

### 角色立绘挑战

- 新增 8×8 遮罩立绘挑战，猜错后逐步揭示更多画面。
- 默认立绘和官方皮肤会公平抽取，但始终计作同一个角色。
- 复用普通角色搜索和完整猜中反馈，好友挑战与回放会保留同一张立绘。

### 角色图鉴与奖励

- 猜中角色后解锁名称、简介、命途、属性、派系、地区、版本和官方立绘资料。
- 完成命途或阵营收集后，可获得对应的全站主题或官方场景壁纸。
- 图鉴奖励支持查看收集进度，未解锁角色不会提前泄露资料。

### 题库与反馈

- 货币战争费用改为完全匹配，补充黄泉等题库资料。
- 注册用户可以在站内提交 Bug、功能建议和数据纠错，并查看处理状态。
- 反馈截图会在上传前压缩，减少提交和审核时的等待。

### 更快，也更稳

- 我们花了一轮时间整理统计、周赛和回放等常用页面，让它们少绕一点路、少等一会儿。
- 日常操作会更顺畅，尤其是在手机或网络状态不太稳定的时候。
- 每日题现在对所有玩家使用同一个答案，体验更公平，也让整个流程更简单可靠。

特别感谢小黑盒用户 `@Ray666666` 提出的反馈与建议，帮助我们把挑战入口、反馈流程和图鉴体验继续打磨。也感谢每一位提交反馈、纠正资料和参与测试的玩家。祝各位早日猜中！

## 工程更新

- TypeScript 升级至 7.0.2 native compiler，保留浏览器、Cloudflare Workers、shared packages 和 Bun tooling 的 runtime 边界。
- 移除 `concurrently`，使用 Bun 1.4 原生并行脚本编排。
- 修复每日榜空数据断言与 API 契约不一致的问题：无成绩返回 `200 + []`。
- 更新 Hono、nanoid 和 undici 的安全版本；`bun audit` 当前无漏洞。
- 保留 Wrangler、Cloudflare Vitest pool、Vite、sharp 和 D1 架构。
- 整理常用数据读取路径，降低统计、周赛和回放功能的后台开销。
- 全仓 Prettier 格式检查恢复为绿色。
