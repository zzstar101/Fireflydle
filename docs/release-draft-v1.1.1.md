# 萤一把 v1.1.1「无尽图鉴解锁修复」

> v1.1.1 正式发布日志。

<!-- fireflydle:announcement:start -->

## 这次，猜中的无尽也算数了

上一版发布后，我们发现一个很容易被忽略的问题：在无尽模式里猜中的角色，明明已经是一次正式的胜利，却没有同步到角色图鉴里。

这次修复后，普通角色无尽模式中的每一次猜中都会解锁对应角色的图鉴资料。之前已经猜中过的无尽记录也会自动补上，不需要重新挑战。

无尽挑战现在也可以随时主动结束：当前通关数和本题已经使用的猜测次数都会立即结算。点击结束后还会再确认一次，避免一时手滑中断挑战。

管理后台也补上了反馈审核入口。站内提交的 Bug、建议和数据纠错现在可以被集中查看和处理，状态更新后会同步回“我的反馈”；标记为已解决时，也会明确显示对应版本。反馈提醒邮件也换成了专用模板，信息更清楚，不会再伪装成一封运维告警。

感谢大家在发布后的测试和反馈，让这个细节没有继续藏在角落里。希望这次你在无尽里猜中的每一个角色，都能真正留在自己的收藏里。

## 工程更新

- 图鉴解锁查询同时读取普通对局与普通角色无尽胜局。
- 增加无尽解锁回归测试，覆盖实时解锁行为。
- 无尽挑战支持主动结算，并以二次确认防止误触。
- 管理后台增加反馈列表、详情、附件预览、状态审核与解决版本登记。
- 新增专用反馈通知邮件模板，并支持从邮件直达审核入口。
- 全部工作区版本同步至 `1.1.1`。
