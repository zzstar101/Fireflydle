# 萤一把 v1.1.2「立绘无尽、反馈追踪与图鉴修复」

> v1.1.2 正式发布日志。

<!-- fireflydle:announcement:start -->

## 让无尽能继续，让反馈有下文

上一版发布后，部分玩家遇到了立绘无尽一直无法开始的问题。这次已经修复，现在可以正常开启新的挑战，也可以回到之前没有完成的对局继续游玩。

反馈中心也补上了后续追踪。站内反馈被管理员审核并采纳后，管理员可以将它发布到公开的问题处理流程；发布成功后，玩家可以在“我的反馈”里查看对应链接，不必再到站外重复填写。联系邮箱和上传的截图仍然只用于审核，不会出现在公开内容中。

图鉴里的命途奖励也重新校对了一遍。此前部分命途与星神图片对应错误，例如“毁灭”错误显示了阿哈；现在九个命途都已经换回正确的星神图片。奖励图片同时改为铺满展示，并针对不同星神调整了主体位置，让卡片看起来更完整。

货币战争题库同步修正了黄泉的羁绊，现在会正确显示为“减益”和“巡海游侠”。

个人战绩页增加了累计猜中数、正确率，以及最常猜中的角色命途和属性；平均猜测次数也调整为只统计真正猜中的题目。

感谢指出这些问题并耐心协助测试的玩家。看起来只是几处小修补，但每一条及时、具体的反馈，都在帮助萤一把变得更可靠。

## 工程更新

- 更新无尽模式数据库约束，使立绘无尽可以正常创建和恢复，同时保留已有记录。
- 增加立绘无尽回归测试，覆盖首次创建与恢复未完成对局。
- 后台反馈审核支持将已采纳条目发布为 GitHub Issue，并保存 Issue 编号与链接。
- 同一条反馈不会重复创建 Issue，公开正文不会包含联系邮箱和站内附件。
- 服务端异常日志补充错误类型、原因与堆栈摘要，便于定位线上问题。
- 修正九个命途与星神图片的映射，并为铺满展示设置独立主体焦点。
- 修正货币战争中黄泉的羁绊数据，并增加题库回归测试。
- 个人战绩增加累计猜中、正确率和命途/属性优势统计，并统一普通挑战、每日题与普通角色无尽的统计口径。
- 全部工作区版本同步至 `1.1.2`。
