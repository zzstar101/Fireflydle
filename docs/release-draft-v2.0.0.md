# 萤一把 v2.0.0「星轨新界面」

> v2.0.0 正式发布日志。

<!-- fireflydle:announcement:start -->

## 全新的星空界面

萤一把换上了全新的界面：总站、对局、结算和其余页面都统一成新的星空主题。顶部导航更精简，手机上改为底部标签栏，切换总站、排行、图鉴和个人页面更顺手。

## 对局更快开始

- 去掉了开局前的准备页，进入玩法就能直接猜；计时从第一次猜测开始。
- 猜测栏就是棋盘上的当前一行，回车即可提交；手机上猜测栏固定在屏幕底部，单手也方便输入。
- 每一格的判定结果会依次亮起，命中越多，星空越暖。

## 新的结算演出

猜中后会先回放这一局的推理过程：全部候选角色排成星旋，每猜一次就淘汰一批，直到只剩答案。随后答案立绘会由星尘汇聚而成，再展示本局用时、每一猜后剩余候选数和分享按钮。演出可以随时跳过；同一局只完整播放一次，之后打开会直接显示结果。

## 其他页面

- 无尽、立绘挑战、周赛、实时对战与好友房、排行榜、图鉴、反馈、账号和规则页面都已换上新主题。
- 图鉴的命途和阵营奖励改为完整方图展示；知更鸟·晴歌、砂金·戏浪和真珠的图鉴卡片补上了高清头像。
- 无尽模式结束后会显示本局通关数和总猜测数，不再留下空白棋盘。

原有账号、战绩、Elo 和图鉴进度不受影响，无需重新登录或重置。

## 工程更新

- 按 `docs/design/redesign-v2/prototype.html` 重写 Web 前端外壳、总站、对局和结算页。
- `apps/web/src/fx` 重写为原型的 S/FX 语义（tween / set / setText / setPortrait / burst），总站 hero 与结算立绘共用同一套 Three.js 点云；删除旧的 point-field、stardust 与 glyph-sampler。
- 结算揭晓移植原型 playResult 时间线：推理回放螺旋 → 闪光 → 立绘点云汇聚 → 面板滑入；回放雪碧图改为百分比定位，移动端放大后不再错位。
- 新增角色高清头像、半身立绘点云和回放雪碧图构建管线；推理评分与实体化复盘进入 game-engine。
- 新增好友房 PartyRoom 与派对目录 API。
- 其余页面统一使用 v2 设计令牌、页头、面板、按钮和输入样式；移除浅色主题。
- 全部工作区版本同步至 `2.0.0`。
