- 角色同步接入 4.7 官网角色数据：89 位官网角色 + 5 个开拓者形态，共 94 位可玩角色；星神★阿哈暂以官网命名空间 `hoyo:89` 标识，等待 StarRailRes 收录后自动切换正式游戏 ID。

- `CurrencyWarsCostSchema` 费用上限由 5 扩至 7，以支持阿哈的 4/5/7 费形态。
- 补齐真珠高清头像索引，角色图鉴索引更新为 93 个角色。
- `bun run verify` 通过：格式、typecheck、资源构建与校验、全部测试、生产构建均成功。
