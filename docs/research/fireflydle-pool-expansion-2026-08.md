# Fireflydle 题库扩展调研：货币战争单位与高知名 NPC

快照日期：**2026-08-18（UTC+8）**。

本文回答两个问题：

1. 货币战争应否只放少数角色，还是覆盖官方当前可玩单位全集；
2. NPC 模式应优先加入哪些高知名、容易辨识且可公平判题的个体。

本文使用 HoYoverse/HoYoLAB 官方一手接口和官方版本内容接口。HoYoWiki 是官方托管的图鉴，但没有稳定 API SLA；每次扩池都必须保存新的抓取日期、页面 ID 和规则快照。公开页面/图片可读不等于获得素材再分发许可。

## 结论

### 用户确认的产品决策（2026-08-18）

- 用户确认将上一轮列出的 64 个缺口全部列为币战补入范围。
- `银狼LV.999` 按产品规则固定为 **3 费**，不采用页面上的多费用展示。
- 这 64 个补入范围与当前官方反向并集 66 个单位、社区目录 72 个单位之间仍存在版本/形态差异；在发布前必须逐条按官方页面 ID 和游戏内图鉴核对，不能用普通角色数据补齐差异。
- NPC 继续评估；下一轮优先审核奥列格、史瓦罗、柯柯娜、查德威克，其他争议条目保持 pending。

### 货币战争

当前官方货币战争羁绊详情反向引用了 **66 个 `menu_id=164` 角色单位**。这些单位出现在 `羁绊角色` 字段，属于货币战争自己的角色命名空间；它们不应再映射到普通角色题池。Fireflydle 若产品定义是“所有实际可玩角色”，建议将这 66 个全部纳入货币战争正式候选/答案池，随后只对缺费用、站位或素材的单位补齐证据，不要继续维持当前仅 6 target + 2 candidate 的人工小池。

当前另外出现的 `专家顾问` 是玩法中的顾问引用，不等同于可招募的羁绊成员。当前 29 个羁绊详情中识别出的顾问名称为：加拉赫、青雀、停云。它们应作为独立的“顾问”玩法数据，不重复计入 66 个普通单位，除非规则明确允许顾问成为答案。

### NPC

官方没有“知名度”字段；知名度是 Fireflydle 的编辑判断。推荐采用三层：

- **已证实可入池**：现有 3 个 target（帕姆、舒翁、斯科特）证据闭合，保留；
- **高知名优先补证**：奥列格、史瓦罗、柯柯娜、查德威克是最值得下一轮审核的扩池对象；它们已有官方 NPC 页、版本锚点、具名任务和完整初步字段；
- **待补证/不要入池**：浮烟、钟表小子、螺丝咕姆、米凯、乔瓦尼、邓恩、蒂索克二世等先保持 pending；黑塔（可玩角色重复）和蒂索克三世（同人格重复）继续 excluded；未在官方 NPC 菜单稳定对齐的 Mikhail、Gopher Wood、Tiernan 不凭社区资料入池。

## 一、货币战争完整单位

### 证据和复现方法

官方入口：

- [HoYoWiki HSR 首页](https://wiki.hoyolab.com/pc/hsr/home)
- [官方菜单接口 `get_menus`](https://sg-wiki-api.hoyolab.com/hoyowiki/wapi/get_menus)
- [货币战争羁绊列表 `get_entry_page_list(menu_id=168)`](https://sg-wiki-api.hoyolab.com/hoyowiki/wapi/get_entry_page_list)
- [货币战争角色详情接口示例：开拓者 `entry_page_id=4274`](https://sg-wiki-api.hoyolab.com/hoyowiki/wapi/entry_page?entry_page_id=4274)

复现步骤：

1. 请求 `get_entry_page_list`，`menu_id=168`，完整读取 29 个羁绊详情页；
2. 逐页读取 `entry_page`，解析 `基本信息` 的 `羁绊角色`，只接受 `menuId=164` 的引用；
3. 按 `ep_id` 去重，得到 66 个稳定单位 ID；
4. 对每个 ID 读取 `menu_id=164` 详情，保存名称、费用、站位、羁绊、头像 URL 和抓取时间。

直接请求 `menu_id=164` 的列表当前只返回最近页面的一小部分，不能把该列表返回数当作全集；羁绊成员反向并集才是目前可重复的全集来源。现有更详细的玩法字段、版本漂移和多语言缺口见 [`fireflydle-currency-wars-bonds.md`](./fireflydle-currency-wars-bonds.md)。

字段方面，当前中文详情并非 66 个都已经提供费用/站位；此前快照显示只有少数中文/英文详情具备结构字段。因此“全集入池”与“字段补齐”应拆开：先锁定 66 个官方单位，缺字段的单位标记 `pendingFields`，不得用猜测或普通角色属性填充。

### 明确不要入池

- `entry_page_id=903` 黑塔：与货币战争/普通可玩角色重复，NPC 模式排除。
- `entry_page_id=2490` 蒂索克三世：按同人格/形态规则合并到蒂索克二世，不创建第二答案。
- 敌人、首领、种族/群体名、无稳定个体身份的对象：不因出现在敌人或其它图鉴菜单而导入 NPC 池。
- Mikhail、Gopher Wood、Tiernan：本快照未在官方 NPC 菜单形成可稳定对齐条目；即使玩家知名度高，也先标为“待补官方条目”，不要用社区页面越过来源门禁。

## 三、对实现和发布的直接建议

1. 货币战争先把 66 个单位作为版本化清单导入，字段缺口用 `pendingFields` 明示；不要继续用 8 个单位假装“完整题库”。
2. NPC 先把奥列格、史瓦罗、柯柯娜、查德威克做成下一轮人工审核清单，审核通过后再提升 manifest；其余 431 条保持 pending，不为凑数量强行入池。
3. 货币战争单位、普通角色、NPC 使用不同 ID 命名空间；同名或同人物不同形态不能自动合并。
4. 每次官方 Wiki 更新都生成新的 `currency-wars`/`npc` manifest 修订，保存抓取时间、来源 URL、页面 ID 和字段哈希；历史对局继续绑定旧快照。
