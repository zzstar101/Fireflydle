# 普通模式 90 角色地区字段来源审计

审计日期：**2026-08-19**。范围是 `packages/game-data/src/generated/characters.json` 中的 90 个普通模式角色形态；不修改运行时代码。

## 结论

1. **90/90 没有角色原始 `regionId`。** `characters.json` 中显式 `regionId` 字段为 0/90；`CharacterSchema` 只把它定义为可选字段（[仓库文件](../../packages/contracts/src/index.ts)）。发布 manifest 由 `regionFor()` 先读取该字段，缺失时按 `REGION_BY_GROUP` 从 `factionGroupId` 派生（[仓库文件](../../packages/game-data/src/content-manifest.ts)）。当前 90 条全部走后者。
2. **BWiki 没有独立地区字段可供直接同步。** 对角色图鉴分类的 Semantic 查询请求 `?阵营|?初始阵营|?派系|?地区`，当前返回 100 个角色页：`阵营` 98 条非空、`初始阵营` 3 条、`派系` 68 条，而 `地区` 0 条。批量查询 URL：[BWiki Semantic API（本次查询）](https://wiki.biligame.com/sr/api.php?action=ask&query=%5B%5B%E5%88%86%E7%B1%BB%3A%E8%A7%92%E8%89%B2%5D%5D%7C%3F%E9%98%B5%E8%90%A5%7C%3F%E5%88%9D%E5%A7%8B%E9%98%B5%E8%90%A5%7C%3F%E6%B4%BE%E7%B3%BB%7C%3F%E5%9C%B0%E5%8C%BA%7Climit%3D500&format=json)。因此本审计中的“地区”不是 BWiki 直接字段。
3. **官方 HoYoWiki 也没有独立地区字段。** `menu_id=104` 的角色筛选器只有 `character_combat_type`、`character_paths`、`character_rarity`、`character_factions`；后者是可多选的统一“阵营”字段。2026-08-19 中文列表返回 90 条、81 条有值、21 个枚举，枚举同时混合地点/世界（如雅利洛-Ⅵ、翁法罗斯）、组织（如星核猎手、星际和平公司）和兜底类别（银河、异界）。来源：[官方筛选器 API](https://sg-wiki-api.hoyolab.com/hoyowiki/wapi/get_menu_filters?menu_id=104)。角色列表通过该[官方角色列表 API](https://sg-wiki-api.hoyolab.com/hoyowiki/wapi/get_entry_page_list) 的 POST 请求体 `{"filters":[],"menu_id":"104","page_num":1,"page_size":50,"use_es":true}` 分两页读取。
4. **地区与阵营必须分开。** 当前 `factionId` 是 BWiki 图鉴单值“阵营”的审核映射，`factionGroupId` 是仓库用于父级接近判定的分组；`regionId` 是 Fireflydle 的题目字段，由分组映射产生，不能宣称为任何上游的原始地区字段。`初始阵营`和`派系`不能替代地区：前者是历史/出身分组，后者是多值组织归属。

## 绯英（Evanescia）重点核对

- BWiki [绯英角色页](https://wiki.biligame.com/sr/%E7%BB%AF%E8%8B%B1) 的结构化属性只有 `阵营=二相乐园`；[browsebysubject API](https://wiki.biligame.com/sr/api.php?action=browsebysubject&subject=%E7%BB%AF%E8%8B%B1&format=json) 没有 `地区` 或 `派系`属性。角色介绍也只写“现身二相乐园”。
- 官方 HoYoWiki [绯英（entry 5005）](https://wiki.hoyolab.com/pc/hsr/entry/5005) 的详情描述同样写“现身二相乐园”，基本信息的“阵营”为空；官方角色页分类频道 `cha_tab_11` 的中/英/日名称分别为“二相乐园 / Planarcadia / 二相楽園”（同一 `iInfoId=162602`），见[中文分类 API](https://sg-public-api-static.hoyoverse.com/content_v2_user/app/113fe6d3b4514cdd/getContentList?iChanId=241&iPage=1&iPageSize=500&sLangKey=zh-cn)和[英文分类 API](https://sg-public-api-static.hoyoverse.com/content_v2_user/app/113fe6d3b4514cdd/getContentList?iChanId=241&iPage=1&iPageSize=500&sLangKey=en-us)。
- 仓库记录是 `factionId=planarcadia`、`factionGroupId=planarcadia`（[generated character](../../packages/game-data/src/generated/characters.json)），再由 `REGION_BY_GROUP` 生成 `regionId=planarcadia`。本次已把展示层同一 ID 的中文地区名从无一手证据的“哀丽秘榭”修正为“二相乐园”，日文同步修正为官方分类“二相楽園”。
- **判断：** 普通模式继续把“二相乐园”作为宽泛地区显示，但不宣称它是上游独立地区字段。

## 需要后续决策的差异

- **绯英：** 已移除没有角色级一手地区证据的“哀丽秘榭”，改用上游明确的“二相乐园”作为宽泛地区显示。
- **仙舟 22 条：** BWiki/HoYoWiki 提供罗浮、曜青、朱明、玉阙等船级地点；仓库将它们统一为 `xianzhou`，这是地区父级的编辑规则，不是上游字段。特别是云璃的 BWiki 阵营为朱明、HoYoWiki 为罗浮，不能用任一阵营值冒充唯一地区。
- **银河 20 条：** 星核猎手、星际和平公司、纯美骑士团、博识学会、流光忆庭、假面愚者、巡海游侠、焚化工以及“银河”均被折叠到 `cosmic`；这是宽泛地区兜底，不代表这些角色共享一个组织。星期日的 BWiki `阵营=银河`、`初始阵营=匹诺康尼`、`派系=家族/天外合唱班`尤其说明三列不可混用。
- **跨作品 4 条：** BWiki 将 Archer/Saber/吉尔伽美什/远坂凛标为“异界(Fate系列)”，官方 HoYoWiki 对 Archer/Saber 当前显示“银河”、对后两者显示“异界”；仓库的 `another-world` 是审核后的跨作品地区，不能声称来自统一官方地区字段。
- **缺失官方阵营不等于缺失地区证据：** 银枝、真理医生、波提欧、知更鸟、星期日、阿格莱雅、爻光、不死途、绯英等官方 HoYoWiki 角色筛选值为空，但仓库仍按 BWiki 或官网分类分组生成地区；这些值都应在同步审计中保留来源层级和人工审核状态。

